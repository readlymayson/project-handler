# Changelog

## [2.0.0] - 2025-09-30

### Изменено (Breaking Changes)

- **Переход на Bitrix24 Document Generator** - генерация документов теперь происходит через встроенную систему Bitrix24 вместо серверной генерации
- Удалена зависимость от PhpSpreadsheet
- Документы теперь создаются по шаблонам, настроенным в интерфейсе Bitrix24

### Добавлено

- Класс `DocumentGenerator` полностью переписан для работы с Bitrix24 API
- Поддержка пользовательских переменных в шаблонах документов
- Автоматическая передача данных в шаблоны:
  - Информация о задачах (дата, название, исполнитель, время)
  - Информация об услугах по ролям (название, количество, цена, сумма)
  - Информация о договорах и приложениях
- Настройки ID шаблонов в `config.php`:
  - `REPORT_TEMPLATE_ID` - ID шаблона отчета
  - `INVOICE_TEMPLATE_ID` - ID шаблона счета
  - `ACT_TEMPLATE_ID` - ID шаблона акта
- Новая документация:
  - `docs/DocumentGeneration_README.md` - полное руководство
  - `docs/QuickStart.md` - быстрый старт

### Удалено

- Зависимость от `phpoffice/phpspreadsheet`
- Серверная генерация Excel файлов
- Директория `documents/` для временных файлов
- Методы генерации документов на сервере (помечены как deprecated)

### Преимущества новой системы

1. **Без внешних зависимостей** - работает только с Bitrix24 API
2. **Централизованное управление** - шаблоны редактируются в Bitrix24
3. **Автоматическое хранение** - документы хранятся в облаке Bitrix24
4. **Гибкость** - легко изменять дизайн без изменения кода
5. **Интеграция** - документы сразу доступны в карточке сделки

## Миграция с версии 1.x

### Что нужно сделать:

1. **Создать шаблоны в Bitrix24**
   - Отчет по задачам
   - Счет
   - Акт

2. **Обновить config.php**
   - Указать ID созданных шаблонов
   - Проверить настройки договоров по умолчанию

3. **Удалить старые зависимости**
   ```bash
   composer remove phpoffice/phpspreadsheet
   ```

4. **Протестировать генерацию**
   ```bash
   php index.php
   ```

### Обратная совместимость

- Основной функционал создания сделок не изменился
- API вызовы для получения данных остались прежними
- Структура логирования сохранена

## Формат документов

### Отчет Excel
- Дата создания задачи
- Наименование задачи
- Кто выполнял (должность)
- Время за отчетный период

### Счет
- Наименование: "Оплата услуг {роль} в {месяц} {год} года по приложению {...}"
- Количество (часы)
- Цена за час
- Ставка НДС
- Сумма

### Акт
- Наименование: "Услуги {роль} в {месяц} {год} года по приложению {...}"
- Остальные поля аналогично счету
