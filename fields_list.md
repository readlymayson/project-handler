# Список полей для компаний

## Основные поля проекта

**Ссылка на проект** (`UF_CRM_PROJECT_LINK`)
- Для чего: Хранение ссылки на проект в Битрикс24 или ID проекта
- Тип: Текстовое поле (string)
- Обязательное: Нет

**Пользователь экстранета** (`UF_CRM_EXTRANET_USER`)
- Для чего: Выбор пользователя для отправки уведомлений
- Тип: Привязка к пользователю (employee)
- Обязательное: Нет

**Лимит часов** (`UF_CRM_HOURS_LIMIT`)
- Для чего: Указание максимального количества часов для проекта
- Тип: Числовое поле с плавающей точкой (double)
- Обязательное: Нет

**Дата уведомления** (`UF_CRM_NOTIFY_DATE`)
- Для чего: Отметка даты последнего уведомления о превышении лимита
- Тип: Поле для выбора даты (date)
- Обязательное: Нет

**Базовая ставка по умолчанию** (`UF_CRM_DEFAULT_RATE`)
- Для чего: Базовая ставка за час работы, если не указаны индивидуальные ставки по ролям
- Тип: Денежное поле (money)
- Обязательное: Нет

## Поля для договоров (опционально)

Эти поля используются для индивидуальных договоров в документах (счета, акты):

**Номер договора** (`UF_CRM_CONTRACT_NUMBER`)
- Для чего: Номер договора для конкретной компании
- Тип: Текстовое поле (string)
- Обязательное: Нет
- Если не указано, используется значение из `config.php` (`DEFAULT_CONTRACT_NUMBER`)

**Дата договора** (`UF_CRM_CONTRACT_DATE`)
- Для чего: Дата договора для конкретной компании
- Тип: Текстовое поле (string)
- Обязательное: Нет
- Если не указано, используется значение из `config.php` (`DEFAULT_CONTRACT_DATE`)

**Номер приложения** (`UF_CRM_APPENDIX_NUMBER`)
- Для чего: Номер приложения к договору
- Тип: Текстовое поле (string)
- Обязательное: Нет
- Если не указано, используется значение из `config.php` (`DEFAULT_APPENDIX_NUMBER`)

**Дата приложения** (`UF_CRM_APPENDIX_DATE`)
- Для чего: Дата приложения к договору
- Тип: Текстовое поле (string)
- Обязательное: Нет
- Если не указано, используется значение из `config.php` (`DEFAULT_APPENDIX_DATE`)

## Поля для сделок

**Исходная компания** (`UF_CRM_ORIGINAL_COMPANY`)
- Для чего: Ссылка на исходную компанию, из которой была создана сделка
- Тип: Привязка к компании
- Автоматически заполняется при создании сделки

**Ссылка на проект** (`UF_CRM_PROJECT_LINK`)
- Для чего: Ссылка на проект, по которому создана сделка
- Тип: Текстовое поле (string)
- Автоматически заполняется при создании сделки

---

## Важные замечания

1. **Все поля не являются обязательными** для заполнения и доступны для поиска и фильтрации.

2. **Приоритет ставок:**
   - Если указана индивидуальная ставка для роли (например, `UF_CRM_FRONTEND_RATE`), используется она
   - Если не указана, используется `UF_CRM_DEFAULT_RATE`
   - Если и она не указана, используется `DEFAULT_HOURLY_RATE` из `config.php`

3. **Время засчитывается роли исполнителя задачи:** Ставка берется для роли исполнителя задачи (RESPONSIBLE_ID), а не для роли того, кто логировал время.

4. **Автоматическое создание полей:** Используйте скрипт `check_uf_crm_company_fields.php` для автоматической проверки и создания всех необходимых полей.
