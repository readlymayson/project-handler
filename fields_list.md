# Список полей для компаний

## Основные поля проекта

**Ссылка на проект**
- Для чего: Хранение ссылки на проект в Битрикс24 или ID проекта
- Тип: Текстовое поле

**Пользователь экстранета**
- Для чего: Выбор пользователя для отправки уведомлений
- Тип: Выбор из списка сотрудников

**Лимит часов**
- Для чего: Указание максимального количества часов для проекта
- Тип: Числовое поле

**Дата уведомления**
- Для чего: Отметка даты последнего уведомления о превышении лимита
- Тип: Поле для выбора даты

## Ставки специалистов (в рублях за час)

**Front-end разработчик**
- Для чего: Указание ставки Front-end разработчика за 1 час работы
- Тип: Денежное поле

**Back-end разработчик**
- Для чего: Указание ставки Back-end разработчика за 1 час работы
- Тип: Денежное поле

**Дизайнер**
- Для чего: Указание ставки дизайнера за 1 час работы
- Тип: Денежное поле

**Проект-менеджер**
- Для чего: Указание ставки проект-менеджера за 1 час работы
- Тип: Денежное поле

**Контент-менеджер**
- Для чего: Указание ставки контент-менеджера за 1 час работы
- Тип: Денежное поле

---

*Все поля не являются обязательными для заполнения и доступны для поиска и фильтрации.*
