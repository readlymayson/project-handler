# Настройка генератора документов

## Обзор

Генератор документов позволяет автоматически создавать отчеты, счета и акты при создании сделок "Работы за предыдущий месяц".

## Настройка

### 1. Включение/выключение генератора

В файле `config.php` установите:

```php
// Включить/выключить генерацию документов
define('ENABLE_DOCUMENT_GENERATOR', true); // true - включить, false - выключить

// Автоматически генерировать документы при создании сделки
define('AUTO_GENERATE_DOCUMENTS', true);

// Генерировать документы сразу при создании сделки
define('GENERATE_ON_DEAL_CREATION', true);

// Генерировать документы при обновлении сделки
define('GENERATE_ON_DEAL_UPDATE', false);
```

### 2. Создание шаблонов в Bitrix24

1. Перейдите в **CRM → Настройки → Шаблоны документов**
2. Создайте шаблоны для:
   - **Отчет** (Excel файл с детализацией времени)
   - **Счет** (PDF документ для выставления счета)
   - **Акт** (PDF документ выполненных работ)

3. Запомните ID созданных шаблонов

### 3. Настройка ID шаблонов

В файле `config.php` укажите ID шаблонов:

```php
// ID шаблонов документов (замените на реальные ID)
define('REPORT_TEMPLATE_ID', 123); // ID шаблона Excel отчета
define('INVOICE_TEMPLATE_ID', 124); // ID шаблона счета
define('ACT_TEMPLATE_ID', 125); // ID шаблона акта
```

### 4. Настройка производительности

```php
// Настройки генерации документов
define('DOCUMENT_GENERATION_TIMEOUT', 60); // Таймаут генерации документа в секундах
define('DOCUMENT_RETRY_ATTEMPTS', 3); // Количество попыток генерации документа
define('DOCUMENT_RETRY_DELAY', 5); // Задержка между попытками в секундах
```

## Проверка настроек

Запустите тест для проверки настроек:

```bash
php test_document_generator.php
```

## Переменные для шаблонов

В шаблонах документов доступны следующие переменные:

### Основные данные
- `{DEAL_TITLE}` - Название сделки
- `{DEAL_ID}` - ID сделки
- `{COMPANY_NAME}` - Название компании
- `{PROJECT_NAME}` - Название проекта
- `{PROJECT_ID}` - ID проекта

### Временные данные
- `{TOTAL_HOURS}` - Общее количество часов
- `{TOTAL_COST}` - Общая стоимость
- `{ROLES_COUNT}` - Количество ролей

### Данные по ролям
- `{ROLE_NAME}` - Название роли
- `{ROLE_HOURS}` - Часы по роли
- `{ROLE_COST}` - Стоимость по роли
- `{ROLE_RATE}` - Ставка по роли

### Данные компании
- `{CONTRACT_NUMBER}` - Номер договора
- `{CONTRACT_DATE}` - Дата договора
- `{APPENDIX_NUMBER}` - Номер приложения
- `{APPENDIX_DATE}` - Дата приложения

## Статусы генерации

- `success` - Документы успешно сгенерированы
- `disabled` - Генератор отключен в настройках
- `error` - Ошибка при генерации
- `partial` - Частично сгенерированы (некоторые шаблоны не настроены)

## Логирование

Все операции генерации документов логируются в файл `logs/document_generator.log`.

## Устранение неполадок

### Генератор отключен
```
Генерация документов отключена в настройках
```
**Решение:** Установите `ENABLE_DOCUMENT_GENERATOR = true`

### Шаблоны не настроены
```
Шаблоны документов не настроены (ID = 0)
```
**Решение:** Создайте шаблоны в Bitrix24 и укажите их ID в config.php

### Ошибка генерации
```
Ошибка при генерации документа: [детали ошибки]
```
**Решение:** Проверьте корректность шаблонов и доступность API Bitrix24

## Примеры использования

### Включение генератора
```php
// В config.php
define('ENABLE_DOCUMENT_GENERATOR', true);
define('REPORT_TEMPLATE_ID', 123);
define('INVOICE_TEMPLATE_ID', 124);
define('ACT_TEMPLATE_ID', 125);
```

### Отключение генератора
```php
// В config.php
define('ENABLE_DOCUMENT_GENERATOR', false);
```

### Проверка статуса
```php
$documentGenerator = new DocumentGenerator($call, $logger);
$settings = $documentGenerator->checkDocumentGeneratorSettings();

if ($settings['is_ready']) {
    echo "Генератор готов к работе";
} else {
    echo "Генератор не настроен";
}
```
