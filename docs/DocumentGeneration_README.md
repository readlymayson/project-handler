# Генерация документов для Bitrix24

## Описание

Система автоматической генерации документов (отчеты Excel, счета, акты) для сделок в Bitrix24.

Система поддерживает два варианта генерации:
1. **ExternalDocumentGenerator** (рекомендуется) - через внешние библиотеки (PhpSpreadsheet для Excel, TCPDF для PDF)
2. **DocumentGenerator** (устаревший) - через встроенную систему Bitrix24 Document Generator

**Примечание:** Excel отчеты теперь генерируются через ExternalDocumentGenerator. Для Bitrix24 Document Generator рекомендуется использовать только шаблоны счетов и актов.

Все затраченное время в задаче засчитывается роли исполнителя задачи (RESPONSIBLE_ID).

## Требования

- PHP >= 7.4
- Доступ к Bitrix24 REST API
- Созданные шаблоны документов в Bitrix24

## Настройка

### Шаг 1: Выбор способа генерации

#### Вариант A: ExternalDocumentGenerator (рекомендуется)

Excel отчеты генерируются автоматически через PhpSpreadsheet. Подробнее: [docs/EXTERNAL_GENERATOR_MIGRATION.md](EXTERNAL_GENERATOR_MIGRATION.md)

#### Вариант B: Bitrix24 Document Generator (устаревший)

Если используете Bitrix24 Document Generator, создайте шаблоны для счетов и актов:

1. Войдите в Bitrix24
2. Перейдите: **CRM → Настройки → Настройка CRM → Шаблоны документов**
3. Создайте шаблоны (Excel отчеты теперь генерируются через ExternalDocumentGenerator):

#### Шаблон 1: Счет

**Название:** "Счет на оплату услуг"

**Поля для использования:**
- `{=INVOICE_NUMBER}` - Номер счета
- `{=COMPANY_NAME}` - Название компании-исполнителя
- `{COMPANY_TITLE}` - Название компании-заказчика (стандартное поле)
- `{=ROLES_DATA}` - Таблица с услугами (массив)
  - `{=ROLES_DATA.NUMBER}` - Номер по порядку
  - `{=ROLES_DATA.SERVICE_NAME_INVOICE}` - Наименование услуги
  - `{=ROLES_DATA.HOURS}` - Количество часов
  - `{=ROLES_DATA.RATE}` - Цена за час
  - `{=ROLES_DATA.AMOUNT}` - Сумма
- `{=VAT_RATE}` - Ставка НДС
- `{=TOTAL_COST}` - Итоговая сумма

**Пример структуры:**
```
СЧЕТ № {=INVOICE_NUMBER}
от {CURRENT_DATE}

Исполнитель: {=COMPANY_NAME}
Заказчик: {COMPANY_TITLE}

| № | Наименование | Кол-во | Ед. | Цена | НДС | Сумма |
|---|-------------|--------|-----|------|-----|-------|
{TABLE=ROLES_DATA}
| {=NUMBER} | {=SERVICE_NAME_INVOICE} | {=HOURS} | час | {=RATE} | {=VAT_RATE} | {=AMOUNT} |
{/TABLE}

ИТОГО: {=TOTAL_COST} руб.
```

#### Шаблон 2: Акт

**Название:** "Акт выполненных работ"

**Поля:** Аналогично счету, но используйте `{=ROLES_DATA.SERVICE_NAME_ACT}` вместо `{=ROLES_DATA.SERVICE_NAME_INVOICE}`

**Поля для использования:**
- `{=ACT_NUMBER}` - Номер акта
- `{=COMPANY_NAME}` - Название компании-исполнителя
- `{COMPANY_TITLE}` - Название компании-заказчика
- `{=ROLES_DATA.SERVICE_NAME_ACT}` - Наименование услуги (без слова "Оплата")
- Остальные поля аналогично счету

### Шаг 2: Получение ID шаблонов (только для Bitrix24 Document Generator)

После создания шаблонов найдите их ID:

1. Откройте список шаблонов
2. Наведите на нужный шаблон
3. В URL вы увидите параметр `ID=XXX` - это ID шаблона

Или используйте API запрос:
```php
$result = $call->callBitrix24API('crm.documentgenerator.template.list', []);
var_dump($result);
```

### Шаг 3: Настройка config.php

Откройте `config.php` и укажите ID созданных шаблонов:

```php
// Для ExternalDocumentGenerator (рекомендуется)
define('ENABLE_EXTERNAL_DOCUMENT_GENERATOR', true);
define('EXTERNAL_EXCEL_GENERATION', true); // Excel отчеты

// Для Bitrix24 Document Generator (устаревший)
define('ENABLE_DOCUMENT_GENERATOR', false); // Рекомендуется отключить
define('INVOICE_TEMPLATE_ID', 124); // ID шаблона счета
define('ACT_TEMPLATE_ID', 125); // ID шаблона акта
```

**Примечание:** `REPORT_TEMPLATE_ID` больше не используется, так как Excel отчеты генерируются через ExternalDocumentGenerator.

### Шаг 4: Настройка UF полей компании (опционально)

Для каждой компании в Bitrix24 можно настроить индивидуальные параметры:

**Пользовательские поля компании:**
- `UF_CRM_CONTRACT_NUMBER` - Номер договора
- `UF_CRM_CONTRACT_DATE` - Дата договора
- `UF_CRM_CONTRACT_DATE` - Дата договора  
- `UF_CRM_APPENDIX_NUMBER` - Номер приложения
- `UF_CRM_APPENDIX_DATE` - Дата приложения

Если эти поля не заполнены, используются значения по умолчанию из `config.php`.

## Генерируемые документы

### Формат наименования услуг

#### Для счета:
```
Оплата услуг {роль} в {месяц} {год} года по приложению {№ приложения} от {дата} к Договору {№ договора} от {дата}
```

**Пример:**
```
Оплата услуг back-end разработчик в августе 2025 года по приложению № 3 от 16.05.24 к Договору № ТЕХНОРЕСУРС/23 от 12.12.23
```

#### Для акта:
```
Услуги {роль} в {месяц} {год} года по приложению {№ приложения} от {дата} к Договору {№ договора} от {дата}
```

**Пример:**
```
Услуги back-end разработчик в августе 2025 года по приложению № 3 от 16.05.24 к Договору № ТЕХНОРЕСУРС/23 от 12.12.23
```

## Использование

### Автоматическая генерация

Документы автоматически генерируются при создании сделки "Работы за предыдущий месяц" в первый день месяца.

**Процесс:**
1. Система создает сделку в Bitrix24
2. Собирает данные о задачах и времени
3. Вызывает API Bitrix24 для генерации документов по шаблонам
4. Документы автоматически прикрепляются к сделке

### Программное использование

```php
require_once 'DocumentGenerator.php';

$documentGenerator = new DocumentGenerator($call, $logger);

// Генерация документов для сделки
$result = $documentGenerator->generateDocumentsForDeal(
    $dealId,           // ID сделки
    $company,          // Данные компании
    $projectTimeData,  // Данные о времени по проекту
    $projectId         // ID проекта
);

if ($result['status'] === 'success') {
    echo "Документы успешно созданы!";
    foreach ($result['documents'] as $type => $doc) {
        echo "\n$type: Document ID = " . $doc['id'];
    }
} else {
    echo "Ошибка: " . $result['message'];
}
```

## Доступные данные для шаблонов

При генерации документов в шаблоны передаются следующие переменные:

### Общие данные
- `MONTH_NAME` - Название месяца (январе, феврале, и т.д.)
- `YEAR` - Год (2025)
- `CONTRACT_NUMBER` - Номер договора
- `CONTRACT_DATE` - Дата договора
- `APPENDIX_NUMBER` - Номер приложения
- `APPENDIX_DATE` - Дата приложения
- `TOTAL_HOURS` - Общее количество часов
- `TOTAL_COST` - Общая стоимость
- `INVOICE_NUMBER` - Номер счета
- `ACT_NUMBER` - Номер акта
- `VAT_RATE` - Ставка НДС
- `COMPANY_NAME` - Название компании-исполнителя

### Массив ROLES_DATA (услуги по ролям)

Каждый элемент содержит:
- `NUMBER` - Порядковый номер
- `ROLE` - Роль (back-end разработчик, front-end разработчик и т.д.)
- `SERVICE_NAME_INVOICE` - Наименование для счета (с "Оплата услуг")
- `SERVICE_NAME_ACT` - Наименование для акта (с "Услуги")
- `HOURS` - Количество часов
- `RATE` - Ставка в час
- `AMOUNT` - Сумма (часы × ставка)

### Массив TASKS_DATA (задачи для отчета)

Каждый элемент содержит:
- `CREATED_DATE` - Дата создания (dd.mm.yyyy)
- `TITLE` - Название задачи
- `EXECUTOR_POSITION` - Должность исполнителя задачи (RESPONSIBLE_ID)
- `HOURS` - Затраченные часы (суммарное время задачи за период)

**Важно:** Поле `EXECUTOR_POSITION` показывает должность исполнителя задачи, а не того, кто логировал время.

## API Bitrix24

Система использует следующие методы API:

### crm.documentgenerator.document.add

Создает документ по шаблону.

**Параметры:**
- `templateId` - ID шаблона
- `entityTypeId` - Тип сущности (2 = Deal)
- `entityId` - ID сущности (ID сделки)
- `values` - Дополнительные значения для шаблона

**Пример:**
```php
$result = $call->callBitrix24API('crm.documentgenerator.document.add', [
    'templateId' => 123,
    'entityTypeId' => 2,
    'entityId' => 456,
    'values' => [
        'MONTH_NAME' => 'августе',
        'YEAR' => '2025',
        'TOTAL_HOURS' => 160
    ]
]);
```

## Логирование

Все операции логируются:

**Успешная генерация:**
```php
[
    'success' => 'Документ успешно сгенерирован',
    'document_id' => 789,
    'template_id' => 123
]
```

**Ошибка:**
```php
[
    'error' => 'Ошибка при генерации документа из шаблона',
    'template_id' => 123,
    'error_message' => 'Описание ошибки'
]
```

## Troubleshooting

### Шаблоны не найдены

**Проблема:** "Не настроены ID шаблонов документов в config.php"

**Решение:**
1. Создайте шаблоны в Bitrix24
2. Найдите их ID
3. Укажите ID в `config.php`

### Ошибка прав доступа

**Проблема:** "ERROR_CORE: Access denied"

**Решение:**
1. Проверьте права webhook
2. Убедитесь, что webhook имеет права на:
   - `crm` (управление CRM)
   - `documentgenerator` (генерация документов)

### Документы создаются пустыми

**Проблема:** Документы создаются, но без данных

**Решение:**
1. Проверьте правильность плейсхолдеров в шаблонах
2. Используйте `{=VARIABLE_NAME}` для пользовательских переменных
3. Используйте `{FIELD_NAME}` для стандартных полей сущности
4. Проверьте логи на наличие переданных данных

### Неправильное форматирование таблиц

**Проблема:** Таблицы в документах отображаются неправильно

**Решение:**
1. Используйте правильный синтаксис:
```
{TABLE=ARRAY_NAME}
  {=ARRAY_NAME.FIELD}
{/TABLE}
```
2. Проверьте документацию Bitrix24 по работе с таблицами в шаблонах

## Преимущества использования Bitrix24 Document Generator

1. **Нет внешних зависимостей** - не требуется PhpSpreadsheet или другие библиотеки
2. **Централизованное управление** - шаблоны редактируются в интерфейсе Bitrix24
3. **Автоматическое хранение** - документы хранятся в Bitrix24
4. **Версионность** - Bitrix24 отслеживает историю изменений шаблонов
5. **Гибкость** - легко изменять дизайн и структуру документов без изменения кода
6. **Интеграция** - документы сразу доступны в карточке сделки
