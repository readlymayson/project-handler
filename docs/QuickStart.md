# Быстрый старт: Генерация документов в Bitrix24

## Кратко о системе

Система автоматически создает сделки "Работы за предыдущий месяц" и генерирует к ним документы (отчет, счет, акт) через встроенную систему Bitrix24.

## За 5 минут до запуска

### 1. Создайте шаблоны в Bitrix24

**Где:** CRM → Настройки → Настройка CRM → Шаблоны документов

Создайте 3 шаблона для **Сделки**:

#### Шаблон "Отчет по задачам"

Содержимое (пример для Word/DOCX):

```
ОТЧЕТ ПО ЗАДАЧАМ ЗА {=MONTH_NAME} {=YEAR}

Дата создания | Наименование задачи | Исполнитель | Часы
-------------|-------------------|------------|------
{TABLE=TASKS_DATA}
{=TASKS_DATA.CREATED_DATE} | {=TASKS_DATA.TITLE} | {=TASKS_DATA.EXECUTOR_POSITION} | {=TASKS_DATA.HOURS}
{/TABLE}

ИТОГО ЧАСОВ: {=TOTAL_HOURS}
```

#### Шаблон "Счет"

```
СЧЕТ № {=INVOICE_NUMBER}
от {CURRENT_DATE}

Исполнитель: {=COMPANY_NAME}
Заказчик: {COMPANY_TITLE}

№ | Наименование | Кол-во | Ед. | Цена | НДС | Сумма
--|-------------|--------|-----|------|-----|-------
{TABLE=ROLES_DATA}
{=ROLES_DATA.NUMBER} | {=ROLES_DATA.SERVICE_NAME_INVOICE} | {=ROLES_DATA.HOURS} | час | {=ROLES_DATA.RATE} | {=VAT_RATE} | {=ROLES_DATA.AMOUNT}
{/TABLE}

ИТОГО: {=TOTAL_COST} руб.
```

#### Шаблон "Акт"

```
АКТ № {=ACT_NUMBER}
выполненных работ от {CURRENT_DATE}

Исполнитель: {=COMPANY_NAME}
Заказчик: {COMPANY_TITLE}

№ | Наименование | Кол-во | Ед. | Цена | НДС | Сумма
--|-------------|--------|-----|------|-----|-------
{TABLE=ROLES_DATA}
{=ROLES_DATA.NUMBER} | {=ROLES_DATA.SERVICE_NAME_ACT} | {=ROLES_DATA.HOURS} | час | {=ROLES_DATA.RATE} | {=VAT_RATE} | {=ROLES_DATA.AMOUNT}
{/TABLE}

ИТОГО: {=TOTAL_COST} руб.
```

### 2. Найдите ID шаблонов

После создания шаблонов:
1. Откройте список шаблонов
2. Наведите мышкой на каждый шаблон
3. В адресной строке браузера будет `...&ID=123...`
4. Запишите эти ID

### 3. Настройте config.php

Откройте файл `config.php` и укажите ID шаблонов:

```php
// Было:
define('REPORT_TEMPLATE_ID', 0);
define('INVOICE_TEMPLATE_ID', 0);
define('ACT_TEMPLATE_ID', 0);

// Стало (укажите ваши ID):
define('REPORT_TEMPLATE_ID', 123);
define('INVOICE_TEMPLATE_ID', 124);
define('ACT_TEMPLATE_ID', 125);
```

Также проверьте настройки договора по умолчанию:

```php
define('DEFAULT_CONTRACT_NUMBER', '№ ТЕХНОРЕСУРС/23');
define('DEFAULT_CONTRACT_DATE', '12.12.23');
define('DEFAULT_APPENDIX_NUMBER', '№ 3');
define('DEFAULT_APPENDIX_DATE', '16.05.24');
```

### 4. Запустите скрипт

```bash
php index.php
```

**Готово!** Система создаст сделки и документы автоматически.

## Что происходит при запуске

1. **Сбор данных:** Система находит все компании с привязанными проектами
2. **Расчет времени:** Собирает время по задачам за предыдущий месяц
3. **Создание сделки:** Создает сделку в воронке "Работы за предыдущий месяц"
4. **Генерация документов:** Вызывает Bitrix24 API для создания документов
5. **Прикрепление:** Документы автоматически прикрепляются к сделке

## Настройка для разных компаний

### Индивидуальные договоры

Для каждой компании можно указать свой договор. Создайте UF поля:

1. Перейдите: **CRM → Настройки → Настройка CRM → Пользовательские поля → Компания**
2. Создайте поля:
   - `UF_CRM_CONTRACT_NUMBER` (Тип: Строка)
   - `UF_CRM_CONTRACT_DATE` (Тип: Строка)
   - `UF_CRM_APPENDIX_NUMBER` (Тип: Строка)
   - `UF_CRM_APPENDIX_DATE` (Тип: Строка)

3. Заполните в карточке компании:
   ```
   Номер договора: № COMPANY/2024
   Дата договора: 01.01.2024
   Номер приложения: № 1
   Дата приложения: 15.03.2024
   ```

### Индивидуальные ставки

Система автоматически берет ставки из полей компании:
- `UF_CRM_BACKEND_RATE` - ставка back-end разработчика
- `UF_CRM_FRONTEND_RATE` - ставка front-end разработчика
- `UF_CRM_DESIGNER_RATE` - ставка дизайнера
- `UF_CRM_PM_RATE` - ставка проект-менеджера
- `UF_CRM_CONTENT_MANAGER_RATE` - ставка контент-менеджера

Если не указаны, используется `DEFAULT_HOURLY_RATE` из config.php.




### Проверьте сделки в Bitrix24

1. Откройте **CRM → Сделки**
2. Выберите воронку "Работы за предыдущий месяц"
3. Откройте созданную сделку
4. Во вкладке "Документы" должны быть 3 файла

## Частые вопросы

**Q: Документы не создаются**
- Проверьте, указаны ли ID шаблонов в config.php
- Проверьте права webhook на доступ к documentgenerator
- Посмотрите логи на наличие ошибок

**Q: Документы пустые**
- Проверьте синтаксис плейсхолдеров в шаблонах
- Для пользовательских переменных используйте `{=VAR_NAME}`
- Для стандартных полей сделки используйте `{FIELD_NAME}`

**Q: Таблицы не отображаются**
- Используйте синтаксис: `{TABLE=ARRAY_NAME}...{/TABLE}`
- Внутри таблицы обращайтесь к полям: `{=ARRAY_NAME.FIELD}`

**Q: Неправильное наименование услуг**
- Проверьте настройки договора в config.php
- Проверьте UF поля компании (если используются индивидуальные договоры)
